# Small Orbit live: endless Langton's ant
Random turmite rules, slow start, exponential speed-up, endless procedural lo-fi.
Runs on GitHub Actions. Needs repo secret `YT_STREAM_KEY`. Start with Actions > live > Run workflow.
Each run streams ~5h55m and starts the next run 10 min before it ends (alternating YouTube primary/backup ingest) so the broadcast never drops.
